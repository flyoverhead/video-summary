# Changelog

## 2026-10-21

- Plugin skeleton, shared helpers (`scripts/common.py`), default parameters and the bundled DJI Osmo Action 6 D-LogM to Rec.709 LUT.
- Agents `frame-analyst` (moment scoring, routine tagging) and `clip-editor` (clips.json per type and tone).
- `scripts/project.py`: `write` for brief.json, clips.json, config.json and SUMMARY.md (diff shown, refuses without `--overwrite`) and `summary` for the pre-render summary with the estimated time and blurred-fill clips.
- `moments.py`: `merge` (validated frame-analyst scores), `pending` (unscored ids in batches) and `pick` (swap or drop a routine group pick); shortlist numbers groups `g1`, `g2`, ….
- `lut.py set`: records per-file LUT decisions in moments.json and clips.json.
- `lut.py show`: prints the recorded per-file LUT decision for every clip and checks `clips.json` against it (exit 1 on a mismatch); grade validates with it instead of reading `moments.json`.
- No automatic D-LogM detection: calibration on real Osmo Action 6 footage found no frame statistic that separates D-LogM from Rec.709 at clip level, so `lut.py detect` lists every clip as `unknown` with its camera source (`dji` when the file has the `djmd` track) and the `defaults.json` `lut` thresholds are gone. grade previews one clip per folder and source and records only the user's answer.
- `render_summary.py` refuses a `config.src` that is not the project argument, and expands `~` in `src`, `out`, `tmp`, `lut` and `music.file` the same way validation does; validation refuses a missing music file.
- grade adds a `Suggest:` line from the camera-source split (dji on, other off), still recorded only after the user's explicit answer. `lut.py detect` and `show` report a missing or malformed project file as `ERROR:` with exit 1.
- Skills `start`, `analyze`, `plan`, `grade`, `render`, `verify` with references `shapes.md`, `schemas.md` and `dji-known-issues.md`.
- Routine groups carry stable ids; `moments.py pick` marks drops instead of removing groups and stores choices in `group_overrides`, re-applied by `group`. Shortlist defaults `--top` from the target length and reports hidden highlights. frame-analyst writes scores to a cache file that `merge` reads. Workflow order is analyze → grade → plan.
- Quality presets follow `hevc_videotoolbox -q:v` (higher is better): draft 40, standard 60 (default), high 75; `--draft` renders at 35. Presets live in `defaults.json` `render.quality`.
- Output confinement: `common.output_path` accepts only the JSON/MD allowlist plus `SUMMARY_VIDEO.mp4` and `SUMMARY_VIDEO.draft.mp4`. `render_summary.py` runs `verify.validate` before any encode and refuses an `out` outside the project root, not named `SUMMARY_VIDEO.mp4`, or listed in `probe.json`, a `tmp` inside the project, and trims past a clip's probed duration (+0.1 s). Validation reports malformed `config.json`, `clips.json` and `probe.json` as problems instead of raising.
- `verify.py` prints `Output:`, `Duration:`, `Size:` and `OK` or `PROBLEM:` lines itself, and reports malformed plan files instead of raising; render and verify skills rely on it, not on hook output. The post-render hook emits that report as `hookSpecificOutput.additionalContext` JSON so it reaches the model when the hook fires.
- Agent inputs scale with footage: `moments.py pending` writes a compact per-batch input file (id, file, t, thumb, clip duration, existing process labels) and prints it next to the scores path; frame-analyst reads only that and `brief.json`. `moments.py digest` writes a compact cache digest (clips, must-find, groups, one line per scored candidate by rank) that clip-editor and grade read instead of `moments.json`. Shortlist group lines list their member ids.
- Must-find recall without blowing the cut: the must-find table carries `best` (shown as `file @ t` + thumb), `required` (best overall plus best per other clip, always kept by clip-editor) and `extras` (compete by rank). `moments.py uncovered <clips.json|->` lists highlights no clip covers, by rank with must-find ids; plan uses it. Batches that keep failing are halved down to 5; the shortlist lists any still-unscored candidates (file @ t, thumb) and plan may proceed once the user acknowledges them.
- `sample.py` skips a timestamp whose thumbnail fails (stderr warning) instead of aborting the whole sample or rescan, and lists the skipped `file @ t` in its output.
- Cache folders for projects outside `~/Movies/camera` get a path hash suffix, so two same-named folders no longer share thumbnails and scores. A group pick clears an earlier drop. `pending` deletes a stale batch scores file before handing out its path and `sample.py --overwrite` clears the cached scores. start warns that music `replace` drops all camera sound.
- End-to-end source-safety test: the full CLI pipeline (brief, probe, sample, pending/merge, group, digest, lut set, clips/config/SUMMARY writes, draft and final render, verify) on a fixture tree only adds the allowlisted files to the project root and leaves every source file and subfolder untouched.
- Eval fixtures use the contract frame shape `wide` (was `landscape`) and the standard quality 60.
- `sample.py` skips clips whose path, base name or folder is listed in `brief.json` `force_exclude` and prints `not sampled (force_exclude): ...`; excluded footage was sampled and scored before (119 of 296 candidates on a real trip). `probe.py` and explicit `--rescan` are unchanged.
